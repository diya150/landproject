# Industrial Land Monitoring System - Quick Start Guide

## 🚀 Getting Started

### Access the System
1. **Log in** to the application
2. Click **"Land Monitoring"** in the left sidebar (top of navigation menu)
3. You'll see the main Integrated Dashboard

---

## 📊 Dashboard Overview

### Top Section: Key Metrics
See at-a-glance statistics:
- **Active Industrial**: 10 plots (Red)
- **Compliant**: 7 industries (Green)
- **Vacant**: 3 plots (Grey)
- **Unusable**: 2 plots (Orange)
- **Disputed**: 1 plot (Yellow)

### Three Main Tabs

#### 1️⃣ **Plot Monitoring Map** (Default)
**What you see**: Interactive GIS-style map of all 16 land parcels

**How to use**:
- **Click any plot** → See full details in right panel
- **Hover over plot** → Quick tooltip appears
- **Legend button** → Show/hide color legend
- **Side panel** → Displays:
  - Plot ID and area
  - Assigned industry
  - Compliance score
  - Environmental status
  - Water access & river distance
  - Constraints (if any)

**Color meanings**:
- 🔴 **Red** = Active industrial (in use)
- ⚪ **Grey** = Vacant (available)
- 🟠 **Orange** = Unusable (environmental issues)
- 🟡 **Yellow** = Disputed (legal conflict)

#### 2️⃣ **Industries Registry**
**What you see**: Database of 10 registered industries

**How to use**:
1. **Search**: Type company name, plot number, or registration ID
2. **Filter**: 
   - By District (Raipur, Durg, etc.)
   - By Industry Type (Manufacturing, Pharma, etc.)
   - By Status (Compliant, Violation, Under Review, Pending)

3. **View Details**:
   - Each card shows company info
   - Contact phone & email
   - Employee count
   - Production capacity
   - Certifications (ISO, WHO GMP, etc.)
   - Environmental clearance status

4. **View on Map**: 
   - Click "View on Map" button
   - Dashboard switches to Plot Tab
   - That industry's plot is highlighted
   - Details show in right panel

#### 3️⃣ **Geographic Overview**
**What you see**: 
- Map of Naya Raipur region
- Key landmarks (Admin Center, River, Industrial Zone)
- Land statistics
- Plot status breakdown

**Features**:
- **Compass**: Shows orientation
- **Scale**: 5km reference scale
- **Fullscreen**: Click expand icon for larger view
- **Statistics**: 
  - Total area: 176.5k m²
  - Average compliance: 85%
  - Industries: 10
  - Districts: 2

## 🎯 Common Tasks

### Find a Specific Industry
1. Go to **Industries Registry** tab
2. Type company name in search box
3. Click **"View on Map"** to see its plot

### Check Compliance Status
1. **Registry Tab**: Look for status badge (green/red/yellow)
2. **Compliance score**: Number out of 100 (higher is better)
3. **Violations**: Red badge = immediate attention needed

### Identify Available Land
1. Go to **Plot Monitoring Map**
2. Look for **Light Grey** plots
3. These are **PLT-011, PLT-012, PLT-013**
4. Click to see exact area and constraints

### Avoid Problem Areas
1. **Orange plots** = Environmental constraints (flood, wetland)
2. **Yellow plots** = Legal disputes (ownership conflict)
3. Check **Constraints** section in plot details

### Review Environmental Data
1. Click on any plot
2. See in right panel:
   - **Environmental Status**: Green/Yellow/Amber/Red
   - **Soil Quality**: Good/Fair/Poor
   - **Water Access**: Yes/No
   - **River Proximity**: Distance in km
   - **Last Inspection**: Date of inspection

## 🔍 Understanding the Data

### Compliance Scores
- **96+** = Excellent (Example: InfoTech Solutions Hub)
- **90-95** = Very Good (Example: Bhilai Steel, Pharma Industries)
- **85-89** = Good (Example: Textiles, Chemical)
- **80-84** = Acceptable (Example: Precision Tools)
- **75-79** = Needs Review (Example: Electronics, AutoParts)
- **62-74** = Violation (Example: Agro Foods - Expired clearance)

### Environmental Status Colors
- 🟢 **Green** = Fully compliant, no issues
- 🟡 **Yellow** = Minor concerns, monitoring
- 🟠 **Amber** = Moderate concerns, review needed
- 🔴 **Red** = Critical issues, violation

### Certifications (What They Mean)
- **ISO 9001** = Quality management
- **ISO 14001** = Environmental management
- **OHSAS 18001** = Health & safety
- **WHO GMP** = Pharmaceutical quality standard
- **DCGI Approved** = Pharmaceutical regulatory approval
- **FSSAI** = Food safety authority
- **ISO 27001** = Information security
- **IATF 16949** = Automotive quality

## 🆘 Troubleshooting

### Map Not Loading
- Refresh page (F5)
- Check internet connection
- Clear browser cache
- Try different browser

### Can't Find Industry
- Check spelling of company name
- Try searching by plot number
- Use filters instead of search
- Contact administrator

### Plot Details Not Showing
- Click directly on colored area
- Ensure plot has click area (min 50px in SVG)
- Hover first to see tooltip
- Try clicking again

### Export Not Working
- Check browser pop-up settings
- Allowed file downloads
- Sufficient disk space
- Try different browser
